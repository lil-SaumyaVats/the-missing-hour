# 🕰️ The Missing Hour

A terminal-based mystery thriller game built in Python.

## About
You wake up with an entire hour of your memory gone — 11 PM to 12 AM, vanished. Investigate clues, make choices, and uncover the truth. Every decision leads to a different ending.

## How to Run
```bash
python terminal_game.py
```

## Features
- Branching storyline with multiple paths
- 4 different endings
- Built with Python basics: print, input, if/elif

## Built With
Python 3 — as a beginner project while learning through Codedex
